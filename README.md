## Pest Detection AI

Проект использует искусственный интеллект и методы обработки изображений для автоматического обнаружения вредителей на листьях сельскохозяйственных культур.
Модель обучается распознавать разницу между изображениями с вредителями и без них, помогая агрономам и исследователям быстрее выявлять угрозы урожаю.

### Описание задачи

Современные технологии компьютерного зрения позволяют автоматизировать процесс мониторинга состояния растений.
Цель данного проекта — создать CNN-модель (сверточную нейронную сеть), которая классифицирует изображения на два класса:

no_pests — растения без вредителей;

 pests — растения, поражённые вредителями.

### Функциональные возможности

1. Загрузка и подготовка изображений;

2. Автоматическая разметка данных по категориям;

3. Обучение модели CNN с использованием TensorFlow;

4. Проверка точности модели на тестовых данных;

Предсказание наличия вредителей на новых изображениях.

```

│   ├── pests/                # изображения вредителей

│   └── dataset_split.py      # разделение данных на train/test
│
├── models/
│   └── pest_cnn.h5           # сохранённая обученная модель
│
├── src/
│   ├── preprocess.py         # предварительная обработка изображений
│   ├── train_model.py        # обучение модели CNN

│
├── utils/
```

### Технологический стек

 Python 3.10+

 TensorFlow / Keras

 OpenCV

 NumPy / Matplotlib / scikit-learn

 Bash (для Arch Linux и Linux-based систем)

 Запуск проекта (Arch Linux)
# 1. Клонируем репозиторий
```
git clone https://github.com/yourname/pest-detection-ai
cd pest-detection-ai
```
# 2. Делаем скрипт исполняемым
```
chmod +x run.sh
```
# 3. Запускаем установку и обучение
```
./run.sh
```
Пример предсказания
```
python src/predict.py data/pests/test_leaf.jpg
```

Вывод:

Вредитель обнаружен!


или

Вредителей не найдено.

 Оценка точности

После обучения можно проверить качество модели:
```
python src/evaluate.py
```

Пример вывода:
```
 Test Accuracy: 93.47%
```
