## Pest Detection AI

Проект использует искусственный интеллект и методы обработки изображений для автоматического обнаружения вредителей на листьях сельскохозяйственных культур.
Модель обучается распознавать разницу между изображениями с вредителями и без них, помогая агрономам и исследователям быстрее выявлять угрозы урожаю.

### Описание задачи

Современные технологии компьютерного зрения позволяют автоматизировать процесс мониторинга состояния растений.
Цель данного проекта — создать CNN-модель (сверточную нейронную сеть), которая классифицирует изображения на два класса:

no_pests — растения без вредителей;

 pests — растения, поражённые вредителями.

### Функциональные возможности

1. Загрузка и подготовка изображений;

2. Автоматическая разметка данных по категориям;

3. Обучение модели CNN с использованием TensorFlow;

4. Проверка точности модели на тестовых данных;

Предсказание наличия вредителей на новых изображениях.

## Установка окружения

Перед запуском убедись, что у тебя установлен Python **3.9+** и `pip`.

### Создай виртуальное окружение (рекомендуется)
```bash
python -m venv venv
source venv/bin/activate  # Linux / macOS
venv\Scripts\activate     # Windows
```
### Установи все зависимости
```
pip install -r requirements.txt
```
Если файла requirements.txt нет, можешь установить основные пакеты вручную:
```
pip install tensorflow opencv-python numpy matplotlib
```

### TensorFlow может быть установлен без поддержки GPU.
Если у тебя есть видеокарта NVIDIA и драйвера CUDA — можно поставить версию с GPU:
```
pip install tensorflow[and-cuda]
```

## Пример тестирования модели

После обучения можно протестировать модель на отдельных изображениях.

### Вариант 1 — указать путь к файлу вручную:
```bash
python src/predict.py data/test/pests/1.jpg
```
или
```
python src/predict.py data/test/no_pests/3.jpg
```
Вариант 2 — запустить без аргументов (скрипт выберет случайное изображение):
```
python src/predict.py
```
